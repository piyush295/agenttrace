# Contributing to AgentTrace

Thanks for your interest in improving AgentTrace. This is a defensive DFIR tool;
all contributions must keep it that way (see the authorized-use notice below).

## Development setup

AgentTrace has **zero runtime dependencies** (standard library only), so setup is
minimal:

```bash
git clone <your-fork-url>
cd agenttrace
python3 -m pip install -e .        # editable install (adds the `agenttrace` CLI)
```

Python 3.10+ is required.

## Running the tests

The suite uses stdlib `unittest` and runs fully offline (no network, no external
services):

```bash
python3 -m unittest discover -s tests -v
```

Everything is exercised against synthetic data generated by `tests/synthetic.py`.

## Project layout

```
agenttrace/
  model.py         # Unified Forensic Event schema, evidence bundle, redaction
  custody.py       # tamper-evident chain-of-custody ledger
  collectors/      # pluggable ingestion (otel, halo, mcp, vector, oauth, egress, jsonl)
  integrity.py     # hash-chain verification, gap detection, signed manifest
  correlate.py     # timeline + causal graph
  detect.py        # attack-pattern detectors + MITRE ATLAS mapping
  analyze.py       # kill-chain narratives + risk scoring
  bundle.py        # portable signed .tar case bundles
  report.py        # JSON / Markdown / HTML reporting
  cli.py           # command-line interface
tests/             # synthetic data generator + test suite
```

## Adding a new evidence collector

1. Create `agenttrace/collectors/<source>.py` subclassing `Collector`.
2. Implement `sniff(path, sample)` (cheap format detection) and
   `parse(path, raw, artifact_id)` (yield `UnifiedForensicEvent`s).
3. Register it in `agenttrace/collectors/__init__._register_builtins()`
   **before** the permissive `jsonl_llm` fallback.
4. Add a synthetic sample + a test.

## Adding a new detector

1. Add a `detect_<pattern>(recon)` function in `agenttrace/detect.py` returning
   `list[Finding]`. Every `Finding` MUST link back to real `evidence_event_ids`.
2. Add a `ATLAS_MAP` entry so the finding maps to a MITRE ATLAS technique.
3. Register it in `_DETECTORS`.
4. Add a synthetic scenario + a test.

## Code style

- Standard library only for runtime code (keeps the tool air-gap friendly).
- Deterministic and explainable: no ML/AI in the detection path — every finding
  must be traceable to concrete evidence.
- Type hints and docstrings on public functions.

## Authorized-use notice

AgentTrace is a **defensive** forensic tool. Contributions that add attack,
exploitation, surveillance, or covert-monitoring capability will not be accepted.
The tool operates only on evidence the operator is authorized to investigate.
